# Equipment Algo Builder

**Equipment Algo Builder** — настольное инженерное приложение на Rust и `egui`, предназначенное для визуального проектирования, каталогизации и интерактивного пошагового выполнения технологических регламентов, алгоритмов технического обслуживания (ТО) и карт поиска неисправностей оборудования.

---

## Ключевые возможности

### 1. Конструктор схем алгоритмов (Flowchart Builder)
* **Типовые блоки операций:**
  * *Выбор действия (Standard)* — ветвление логики с произвольным числом пользовательских вариантов перехода.
  * *Замер параметра (Measurement)* — контроль числовых величин с автоматической валидацией диапазона допусков (Min/Max, единицы измерения) и ветвлением («Норма» / «Отклонение»).
  * *Требование безопасности (Safety)* — блокирующий шаг с подтверждением выполнения правил охраны труда или обесточивания станка.
* **Интеллектуальная трассировка связей:**
  * Поддержка двух стилей проводки: ортогональная (под углом 90°) и плавные кубические сплайны Безье.
  * Индивидуальное переключение стиля конкретной связи через контекстный клик ПКМ.
  * **Соединители ГОСТ 19.701-90 / ISO 5807 (On-Page Connectors `Ⓐ`):** обратные связи и циклы, идущие вверх по иерархии схемы, автоматически заменяются на парные маркированные коннекторы, предотвращая загромождение схемы длинными перекрещивающимися линиями. Клик по коннектору мгновенно центрирует камеру на целевом узле.
* **Сетка и выравнивание:** точечная сетка с шагом 36 px и переключаемой магнитной привязкой (Snap-to-Grid).
* **Встроенный статический анализатор (Linter):** автоматическая подсветка недостижимых узлов (без входящих связей) и неразрешённых оборванных ветвлений.
* **Навигация и обзор:**
  * Интерактивная миникарта с отображением положения камеры и переключаемой визуализацией связей.
  * Плавное панорамирование холста (СКМ) и масштабирование (30% – 250%).
  * Функция вписывания схемы в экран (*Fit View*).
* **Поиск и история:**
  * Быстрый поиск по названиям и описаниям шагов (`Ctrl + F`) с автоматическим переходом камеры.
  * Глубокая история отмены и повтора операций (`Ctrl + Z` / `Ctrl + Y`) до 40 шагов.
* **Экспорт:** выгрузка схем в PNG высокого разрешения и автономный экспорт/импорт в формате JSON.

---

### 2. Пульт интерактивной диагностики (Diagnostics Runner)
* **Пошаговый режим оператора:** изоляция схемы от случайных изменений и блокировка редактирования.
* **Аудит-маршрут (Breadcrumbs):** наглядная лента пройденных узлов с возможностью мгновенного отката к любому предыдущему шагу.
* **Быстрый ввод:** поддержка цифровых горячих клавиш (`1`, `2`, `3`) для мгновенного выбора вариантов ответа.
* **Проверка замеров «на лету»:** ввод физической величины с клавиатуры с автоматическим определением попадания в допуск и подсвечиванием соответствующей ветви перехода.

---

### 3. Каталог и паспорт оборудования (Procedures Library)
* **Древовидная база регламентов:** автоматическая категоризация процедур по производителям (бренду) и конкретным моделям станков/узлов.
* **Паспорт технологической карты:** хранение заводских номеров, модели оборудования, инвентарного номера, автора документа и даты последнего изменения.
* **Локальное файловое хранилище:** автономное хранение алгоритмов и прикреплённых фотографий инструкций без внешних серверных зависимостей.

## Управление и горячие клавиши

| Комбинация / Действие                  | Область      | Описание                                                      |
| :---                                   | :---         | :---                                                          |
| **2x ЛКМ**                             | Холст        | Создать новый шаг в точке клика                               |
| **ЛКМ (зажать на нижнем порту)**       | Блок         | Вытянуть линию связи к другому блоку                          |
| **ЛКМ по плашке связи**                | Связь        | Разорвать соединение                                          |
| **ПКМ по связи**                       | Связь        | Переключить стиль (90° / сплайн)                              |
| **ЛКМ по коннектору `Ⓐ`**             | Соединитель  | Фокусировка камеры на целевом узле перехода                   |
| **Shift + ЛКМ**                        | Холст / Блок | Множественное выделение прямоугольной областью / группировка  |
| **Delete**                             | Выделение    | Удалить выбранные блоки                                       |
| **Ctrl + Z** / **Ctrl + Y**            | Глобально    | Отмена / Повтор действия                                      |
| **Ctrl + F**                           | Холст        | Поиск по названию и описанию узлов                            |
| **СКМ (зажать колесо)**                | Холст        | Панорамирование камеры                                        |
| **Колесо мыши**                        | Холст        | Масштабирование относительно курсора                          |
| **1, 2, 3**                            | Диагностика  | Выбор варианта перехода в пульте оператора                    |

## Архитектура проекта

Кодовая база спроектирована по модульному принципу с разделением структур данных, рендеринга и работы с файловой системой:

```text
src/
├── main.rs            # Точка входа приложения и запуск цикла eframe
├── app.rs             # Структура состояния AlgoApp, панели интерфейса, хоткеи
├── i18n.rs            # Локализация (Русский / English)
├── models.rs          # Модели графа: Algorithm, Step, StepKind, WireStyle, EquipmentInfo
├── settings.rs        # Конфигурация, сетка и визуальные темы (Dark / Light)
├── storage.rs         # Работа с диском: локальный архив, экспорт/импорт JSON, кеш изображений
├── canvas/
│   ├── mod.rs         # Рендеринг рабочего холста, миникарта, точечная сетка, селекция
│   ├── wires.rs       # Отрисовка прямых ортогональных связей и сплайнов Безье
│   └── connectors.rs  # Отрисовка навигационных кружков-соединителей ГОСТ (A, B, C...)
└── views/
    ├── mod.rs         # Реэкспорт представлений
    ├── inspector.rs   # Инспектор параметров шага и справочный центр
    ├── runner.rs      # Пульт пошаговой диагностики оператора
    ├── archive.rs     # Каталог регламентов с деревом оборудования
    └── modals.rs      # Модальные окна: Паспорт станка, выход, удаление
